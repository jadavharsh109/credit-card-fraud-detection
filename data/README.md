# Dataset Information

This folder contains transaction data for fraud detection:

- **creditcard_sample.csv**: A ready-to-use sample dataset (1,492 rows) containing all 492 fraud cases plus 1,000 genuine transactions. You can immediately load and test this without downloading large files.
- **creditcard.zip**: The compressed full Kaggle dataset (284,807 transactions). Unzip it in this folder to get creditcard.csv.

### Full Dataset Download
You can also download the complete uncompressed dataset directly from Kaggle:
🔗 [Kaggle Credit Card Fraud Detection Dataset](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)
